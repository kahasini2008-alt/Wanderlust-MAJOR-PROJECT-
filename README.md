# 🌍 WanderLust — Travel Accommodation Platform

WanderLust is a full-stack web application that allows users to explore travel accommodation listings and create their own listings. This project was built as part of my web development learning journey.

## ✨ Features

- 🏡 Browse available accommodation listings
- ➕ Create new listings with details and images
- ✏️ Edit and 🗑️ delete listings
- 🗂️ Organize listings by categories, such as Trending, Rooms, Mountains, Castles, and more
- 👤 User authentication and listing ownership
- 💾 Store and manage listing data using MongoDB
- 🖼️ Handle listing image uploads
- 📱 Responsive interface for browsing listings

## 🛠️ Tech Stack

- **Frontend:** HTML, CSS, JavaScript, EJS, Bootstrap
- **Backend:** Node.js, Express.js
- **Database:** MongoDB with Mongoose
- **Authentication:** Passport.js
- **Version Control:** Git and GitHub

## ⚙️ Run Locally

1. Clone this repository:

   ```bash
   git clone https://github.com/kahasini2008-alt/Wanderlust-MAJOR-PROJECT-.git
   ```

2. Navigate into the project folder:

   ```bash
   cd Wanderlust-MAJOR-PROJECT-
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Create a `.env` file with the environment variables required by your application. Use your own credentials and never commit this file.

5. Start the application using the start command configured in `package.json`.

6. Open the local URL shown in your terminal.
